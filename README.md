# Customer Analytics – Online Retail

## Project Overview
This project analyses online retail transactions to understand sales performance, customer purchasing behaviour, and customer value.

The project uses Python for data cleaning and analysis and Power BI for interactive visualisation.

## Business Problem
Raw transaction data does not directly explain sales trends, customer purchasing patterns, or customer value. This project transforms transactional data into meaningful business insights.

## Project Objectives
- Analyse sales and revenue performance.
- Identify top-performing products and customers.
- Understand customer purchasing behaviour.
- Segment customers using RFM analysis.
- Build an interactive Power BI dashboard.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Excel
- Power BI

## Project Workflow
1. Data cleaning using Python.
2. Customer-level aggregation.
3. RFM scoring and customer segmentation.
4. Exploratory data analysis and visualisation.
5. Exporting cleaned analytical data.
6. Interactive dashboard development in Power BI.

## Dashboard
Three report pages:
- Executive Overview
- Sales Analysis
- Customer & RFM Analysis

## Customer Segmentation
Customers are grouped into six segments:
- Champions
- Loyal Customers
- Potential Customers
- At Risk
- Lost Customers
- New Customers

## Project Status
Python analysis and Power BI dashboard completed. Documentation and portfolio preparation in progress.
